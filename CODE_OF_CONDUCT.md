# Code of Conduct

> a mechub project

## Our standard
Be respectful and constructive. Focus on the work. Assume good faith.

Unacceptable: harassment, personal attacks, discriminatory language, or
publishing others' private information.

## Scope
Applies in all project spaces — issues, pull requests, discussions — and when
representing the project publicly.

## Enforcement
Report conduct concerns to the maintainer: open a GitHub issue for public
matters, or use the repository's private Security channel for sensitive ones.
Maintainers may edit, remove, or reject contributions and comments that violate
this policy, and may block repeat offenders.

This is a condensed policy in the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org).
